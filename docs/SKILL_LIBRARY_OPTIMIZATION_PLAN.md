# 技能库下一阶段优化与验收计划

日期：2026-10-29。桌面版发布暂停，本计划优先。面向当前浏览器产品；开发分支不等于已上线。

## 两类问题与已知事实

1. **任务理解与参数可靠性**：缺参时没有清楚追问；已明确的中文、单位和LaTeX参数可能丢失；不同任务被送入同一声场流程。用户原例是4m×3m、刚性壁、c=343m/s、rho=1.21kg/m³的二维房间模态分析，条件足够，不应要求驱动频率、声源或PML。
2. **技能库可读性与能力统计**：同名条目、技术术语和参数包装使用户不知道技能用途；案例条数被误认为能力种类。正式库只读审计为20技能、21版本、重复指纹0，不能据同名推断重复写库；也不能据20条记录宣称掌握20种能力。

已完成的分支修复：保留介质/模态标题；频域概览展开物理参数；复制保留完整参数与结果合同。92项回归通过，尚未正式部署。任务识别、通用追问及房间模态求解尚未完成，不把以上修复算作本计划全部通过。

## 技术方案与边界

- 保持现有本地编排、可选Dify、SQLite和jwave隔离；不引入Open Interpreter或无门槛学习。新增输入合同与能力登记层，不靠堆提示词判断是否可执行。
- `TaskContract v1`规划字段：任务类型/能力版本、几何、介质、边界、激励、所需输出；每个参数含原文片段、规范值、单位和来源状态；还包括缺项、冲突、建议值及确认摘要。原文永不被格式转换覆盖。
- LaTeX只作有界格式解析，不运行表达式、宏或用户代码。支持的等价单位确定性换算；无法确定的记为待确认。推导值显示推导关系；建议默认值须用户接受，不伪装用户给定。
- 追问保留已识别条件，只问该任务真正需要的缺项。房间模态在已给c时不需rho来算频率；参数存在但当前能力未实现时，反馈“不支持”，不能反馈“参数缺失”。
- 参数预览由服务端合同驱动；用户确认绑定合同摘要。正文/参数/边界/结果约定改变后必须重新核对，不能沿用旧执行授权。
- 家族ID与案例指纹分开：家族不参与信任提升；不同边界、材料、结果量或单位合同不得因名称相似合并。跨参数泛化必须有显式范围及独立证据，首批精确复用仍保持。
- 旧数据迁移先在线备份并核对逻辑摘要；新增字段可回退、归类可标为未分类。不得改写已有验证证明、删除迁移行、清空数据库或停用唯一约束。
- 接纳新模态类别前明确受控求解、实际产物、标准比较、运行时与反作弊证据；解析公式和参考表本身不等于模型代码可信。暂不支持的任务不学习。

输入至少覆盖：用户原LaTeX、纯中文、纯文本变量、等价cm/mm、科学记数、缺长度、缺声速、边界未说明、冲突数值、负/零长度、单位不明、三维缺高度、吸声壁、非矩形、混合任务、恶意LaTeX/代码文本；另含现有频域、周期初压、高斯初压及复制请求回归。先冻结不少于24条合同用例，再用真实模型检验其输出，不只测手写解析器。

浏览器截图需显示：已识别任务与参数依据、缺参追问、修正后确认、结果表/图、技能用途与适用范围、首次学习及后续实际复用。技术原始记录另存，面向组员的报告只保留结论、问题、来源、标准、结果对比与截图。

## 房间模态标准

用户原题要求二维刚性矩形：

`f(nx,ny) = (c/2) sqrt((nx/Lx)^2 + (ny/Ly)^2)`，nx、ny为非负整数。默认排除(0,0)并在界面说明；若用户要求包含则按其要求计数。简并频率保留不同阶数组合。

4m×3m、343m/s的前10个非零频率（Hz，展示舍入）：42.875000、57.166667、71.458333、85.750000、103.058674、114.333333、122.108054、128.625000、140.756593、142.916667；权威机器用例保存高精度值及各阶数，展示值不作为宽松容差。

依据：[MathWorks房间模态与FEM对照](https://www.mathworks.com/help/audio/ug/find-room-modes-with-finite-element-analysis.html)说明刚性壁为零Neumann边界、解析频率核对和零频处理；[COMSOL房间本征模态](https://doc.comsol.com/6.4/doc/com.comsol.help.models.mph.eigenmodes_of_room/eigenmodes_of_room.html)提供刚性边界、矩形解析对照及适用限制。原例尺寸来自用户，二维公式是对矩形分离变量解的二维特化，不谎称这组数值原封不动出自其三维示例。
