## 入库与复用
固定来源流水线先在权威SQLite核根期限/撤回、具体运行签名、独立派发、宿主观察和原始数值，再生成Q2候选。接纳阶段再次同事务复核当前版本、精确参数、反馈和不可变接收记录，才接纳固定Q4。正反馈不能授信；部分存储失败只留下候选。普通未认证execute/retry仍最多Q2。
初压与平面波分类由明确签名策略约束；固定配置包括二维网格，不伪造连续源频率。正向路径暂拒派生技能，不能把上游active标签当来源认证。

schema11新增只追加公开证据登记。登记只接受固定配置和有限数值数组、白名单数值摘要、空stderr；不持久化任意日志、备注、秘密或私钥。原始JSON字节用于匹配宿主输出摘要，经过结构和原始物理验证后才存储。只记录摘要不足以在日常生成时重算原始数值，所以这一受限数值存储是必要的。生产数据库未迁移。

## 生成前交付
同版本/参数/证据的明确有期限策略允许日常生成复用；每次仍核当前根撤回、生命周期和原始物理。生成决定绑定原输入和查询SHA、nonce、最多3引用及30秒期限。消费同事务复核并只追加一次交付审计，提交后返回一个固定配方。实际模型/执行器/用户使用未认证，actual_use_authenticated恒false。
公共search仍只读，不接受证明，不返回可执行代码。build_simulation_generation_context只使用服务端登记证据；read_simulation_generation_context根据决定编号在只读快照重新核验后返回上下文。两个工具没有调用者代码/等级/可信布尔/数据库路径输入，默认关闭返回原上下文。

两条生成分支的离线图采用参数适配→严格开关→服务端构建→仅提取编号→服务端重新核验→格式检查→生成。关闭绕过两工具；错误不重试并回退原输入。格式检查本身不是授权器，必须只绑定已配置网关reader输出。旧JSON生成守卫继续拒绝自行声明可信的搜索结果。
