# AcouAgent Windows桌面发行计划

目标：用户安装后从桌面快捷方式启动，在独立窗口中完成自然语言仿真、技能使用和结果查看，不要求安装Git、Python或手工运行命令。首版使用Windows x64，计算运行时仍为Docker Desktop/Linux容器；不把它描述成无运行时或完全离线的单文件程序。

## 阶段与验收

1. **架构与探针**：核对Electron隔离、Docker前提、固定镜像、端口、数据所有权、打包可行性与许可；证明桌面窗口能正确识别未安装Docker，形成安装包。
2. **本地运行管理**：独立Compose项目与命名空间、可重入启动、镜像下载进度、健康/17技能就绪、重复启动锁、错误恢复与安全停止；不影响原Web部署。
3. **桌面产品**：可信管理页与无主机权限的仿真窗口分离；环境准备向导、状态、打开工作台、诊断、数据备份与显式技能扩展准备；模型密钥仍按现有临时会话规则处理。
4. **可安装发行**：Windows EXE安装器、快捷方式、用户数据与程序分离、升级及卸载保留数据、版本/镜像身份、校验和及依赖许可说明。缺少可信签名时明确标为未签名预发布，不伪称无系统提示。
5. **发布验收**：真实已打包EXE窗口；缺运行时/端口占用/下载失败/重复启动；实际独立项目部署、求解与数值验证；升级回退及数据保留；新操作者Windows安装首题；最终独立复核后发布GitHub桌面预发布包。正式稳定版仍需对应真人验收和完整发布门。

## 已确定的技术边界

- Electron桌面主进程管理固定白名单操作；renderer开启sandbox/contextIsolation，关闭nodeIntegration。
- 仅受信的本地管理页允许有限IPC；仿真页面不注入宿主机能力，严格限制导航、新窗口和外部URL。
- Compose资源随安装包提供，使用发行时固定的镜像digest；安装不从main临时下载可变脚本，不要求运行Git构建。
- 独立项目/容器/数据卷，端口只绑定127.0.0.1；不操作用户已有Web部署，不接管任意Docker上下文。
- 随机内部令牌通过Windows系统加密保存，运行时注入子进程环境；日志和诊断脱敏，不写入安装包或源码。
- 保留jwave执行器只读、低权限、无外网、资源及时间限额。退出码0不替代物理验证。
- Docker首次准备可能涉及系统组件、许可接受和重启；引导用户完成，不静默关闭安全策略。已有模型API仍按服务商网络与配额工作。

## 当前基线

桌面候选从 `d3ab537` 开始，固定该版网关镜像；原产品仍为0.1.0测试版。队友随后提交的main改动尚未纳入此安装包，最终发布前须同步并重新核对镜像身份。桌面候选独立分支开发，通过阶段门后合并。
