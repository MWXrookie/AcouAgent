## 问题与标准答案

两题均为二维频域Helmholtz点源：128×128网格、间距1mm、背景声速1500m/s、密度1000kg/m³、频率1500000/(2π)Hz、PML16层、源索引[32,32]、数值源系数1、背景衰减0。B02另在索引[50:90,32:100]矩形区域将声速设为2300m/s。

来源是作者固定提交的[j-Wave跨求解器测试](https://github.com/ucl-bug/jwave/blob/d1918f4e6adbf3822108e0af8034063efed1d581/tests/test_kwave_helmholtz.py)，对应[固定k-Wave数据](https://github.com/ucl-bug/jwave-data/tree/600e50c8b4ac71f0bc344098320a1e30b80ade00/tests/kwave_data)中的`helmholtz_homog.mat`与`helmholtz_heterog_c0.mat`。已再次联网核对作者代码的`p_final`、裁剪比较、全参考场峰值分母和严格阈值规则，下载内容还通过冻结MAT与NPY双重SHA校验。

标准答案是完整独立k-Wave复场的幅值，不是单个峰值或本产品先前运行的图片。误差为内部[16:112,16:112]幅值差的最大值，除以完整参考场幅值峰值；严格小于0.01。首次展示场、独立接纳验证场及复用场均从实际绑定产物重新核对。相位未认证；单位为数值源归一化，不能写成已校准Pa。

## 发现并修复的问题

alpha.2首题失败，记录为LLVM线程创建失败并触发30秒超时，未学入技能。本机Docker暴露20个逻辑CPU，原2 CPU配额并不限制LLVM能看到的CPU集合。

alpha.3使用固定镜像中的无网络、无凭据、无数据挂载探针读取真实允许的CPU编号，再将执行器限制至多两核；兼容单核和不连续编号，不猜测编号0、1必然可用。保留原2 CPU配额、256 PID、4GiB、只读、降权、无外网及30秒限制。安装后同题与第二题通过，43项回归通过。原失败数据保留。
