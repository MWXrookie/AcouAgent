## 当前定位

AcouAgent 是面向本地自部署的自然语言声学仿真系统。发行默认使用项目内
`local` 编排；Dify 是显式兼容后端。用户可以在门户注册临时
OpenAI-compatible BYOK profile，也可以通过环境变量配置长期 profile。

正式仿真主链为：

```text
门户 → 本地编排 → 技能检索 → 模型生成或固定参考
     → FastMCP 共享校验 → jwave executor
     → 确定性物理门 → 审查解释 → 受控学习
```

模型不能覆盖 executor 结果或确定性物理门。生成代码只能进入隔离 executor，
不能在网关进程执行。

## 已完成

- GitHub 干净安装门和跨平台安装器。
- 无 Dify 的默认本地编排。
- 门户临时 BYOK 与环境变量多 profile。
- 17 项固定技能在空数据卷上的 executor 实跑、自举和 Q4 接纳。
- 生成前技能检索、固定参考交付、执行关联、反馈和生命周期。
- 普通成功运行最多形成不可复用的 Q2 candidate。
- 技能库脱敏审计、确定性发布清单和发布前回退分支。
- executor 的只读根、降权、无外网和资源限制。

## 当前开发切片

阶段七已合并脱敏 Doctor、门户模型基础预检和文档状态权威化。当前切片正在准备：

1. 阶段一冻结 30 题的多模型可恢复运行器。
2. 本地编排与发布 Dify 图的同题合同对照。
3. 不含提示词、模型正文、代码、求解器输出或凭据的矩阵证据。

同伴测试反馈的首批工程问题已进入当前候选：local 重试复用纠错经验缓存，
看板保留展开状态并展示确定性分析摘要，管理员重跑继续使用临时令牌鉴权，
`/chat` 的畸形 JSON 返回 400。executor 生产版本漂移仍属于部署验收项。

运行器、墙钟截止和门户临时 BYOK 支持已经完成。真实 Dify lane 已完成 30/30：
20 个正例全部通过确定性门并交付参考，10 个负例零参考；唯一工作流失败为域外负例，
没有超时。两个本地模型 lane 共 60 次仍待操作者提供临时 BYOK profile 和费用授权，
完成后才能关闭对应发布门。执行说明见
`docs/validation/stage7/MODEL_MATRIX.md`。
