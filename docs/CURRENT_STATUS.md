## 当前定位

AcouAgent 是面向本地自部署的自然语言声学仿真系统。发行默认使用项目内
`local` 编排；Dify 是显式兼容后端。用户可以在门户注册临时
OpenAI-compatible BYOK profile，也可以通过环境变量配置长期 profile。

正式仿真主链为：

```text
门户 → 本地编排 → 技能检索 → 模型生成或固定参考
     → FastMCP 共享校验 → jwave executor
     → 确定性物理门 → 审查解释 → 受控学习
```

模型不能覆盖 executor 结果或确定性物理门。生成代码只能进入隔离 executor，
不能在网关进程执行。
