## 当前可交付内容

- 自然语言 → 本地编排 → 技能检索 → 固定参考或受限生成 → executor → 独立物理门 → 报告/图像/看板的主链可用。Dify 是可选兼容后端，无需 Dify 即可安装。
- 17 项固定技能、生成前检索、真实新运行复用、纠错缓存与反馈生命周期已验收。
- 自动学习与用户按标准格式手动添加技能已完成阶段1–6验收；只有通过独立验证和接纳的技能可复用。扩展默认关闭，按[启用指南](skills-next/ENABLE_SKILLS.md)开启，不在无质量门时自动学习。
- 门户临时 BYOK、环境 profile 和原生 Flash/Pro 预设可用；密钥不保存在浏览器持久存储中。
- 保留现有 jwave 沙箱，代码不能在网关内执行。退出码 0 不能替代物理正确，模型说明不能覆盖确定性门。
