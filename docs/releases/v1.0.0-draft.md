# AcouAgent v1.0.0 发布说明草案

> **DRAFT — 尚未发布。** 当前包版本仍为 `0.1.0`，仓库尚未创建 `v1.0.0` 标签或 GitHub Release。

## 本版本目标

AcouAgent 已形成可从 GitHub 检出、通过 Compose 启动的本地声学仿真与技能库系统。网关从当前源码构建，jwave executor 保持隔离，固定技能在空数据卷上经执行与确定性物理门自举。

## 已完成

- 本地编排不依赖 Dify 即可运行；操作者可在门户会话中提供 OpenAI 兼容 BYOK，或用环境变量配置自托管模型 profile。
- 空数据卷可幂等生成 17 项 Q4 active 固定技能，自动学习仍受质量门和开关约束。
- Bash 与 PowerShell 一键安装入口保护既有 `.env`，不会回显 token 或模型凭据。
- GitHub 全新 Ubuntu runner 持续核对启动、源码身份、17 项库存与 executor 安全边界。
- 发行工作流在断网、只读、降权 Linux 容器中持续运行完整单元回归。
- 新人首次自然语言仿真指南和脱敏验收器已提供。
- 技能库审计报告可复算，代码、证据正文、反馈理由和凭据不会进入报告。
- 每个发行提交生成确定性的 Git 快照清单，并作为 Actions 产物保存。
- 脱敏 Doctor 可检查安装配置、运行健康、技能库存、源码身份和 executor 边界。
- 门户可对 BYOK profile 做一次受限基础预检；返回代码不执行，也不进入技能库。

## 安装入口

```bash
bash scripts/install.sh --prepare-only
# 可先启动，再在门户「模型设置」中连接 BYOK；也可预先填写环境变量模型配置：
bash scripts/install.sh
```

Windows PowerShell：

```powershell
.\scripts\install.ps1 -PrepareOnly
# 可先启动，再在门户「模型设置」中连接 BYOK；也可预先填写环境变量模型配置：
.\scripts\install.ps1
```

首次仿真见 `docs/FIRST_SIMULATION.md`。发布前操作见 `docs/validation/stage7/RELEASE_CHECKLIST.md`。

## 已知限制

- 自然语言仿真需要用户提供 OpenAI 兼容模型凭据；门户 BYOK 仅保存在服务进程内存中，重启或过期后需重新连接。
- `healthy=true` 的技能库审计只证明数据库结构与记录一致性，不证明任意场景物理正确、模型采用、真人身份或跨主机认证。
- Dify 保留为迁移对照路径，不是默认运行依赖。
- executor 镜像体积较大，首次拉取时间受网络影响。
