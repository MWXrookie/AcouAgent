# Agent API 与可替换前端验证记录

日期：2026-10-29
范围：聊天核心、模型管理、静态前端、旧接口兼容；不改技能库/知识库维护逻辑、executor 和物理门。

## 实现

- Canonical API：`/api/v1/agent/{info,chat,model-profiles,model-sessions}`。
- `ChatRequest`、`WorkflowEvent`、`BackendInfo`、`BackendCapabilities`、`AgentApiError` 和 `CoreBackend`。
- `LocalCoreAdapter` 提供模型 profile/BYOK/preflight 能力；`DifyCoreAdapter` 只声明实际支持的聊天与技能提示能力。
- 旧 `/chat`、`/api/v1/chat`、`/api/model-profiles`、`/api/byok/session`、`/api/model-profiles/test` 保留并带 `Deprecation` / successor `Link`。
- `dashboard.py` 的聊天 HTML 拆为 `app/web/chat.html`、`chat.css`、`chat.js` 和 `agent-client.js`；静态前端使用 `/api/v1/agent/*`。
- `PORTAL_ALLOWED_ORIGINS` 提供精确来源白名单；默认只允许同源。
- Compose 默认绑定恢复为 `127.0.0.1:8001`。
