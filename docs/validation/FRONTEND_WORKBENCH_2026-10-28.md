## 可重复执行

需已有Node.js、Playwright及本机Chrome；脚本不会安装浏览器。根据本机配置设置地址和输出目录：

```sh
GW_BASE_URL=http://127.0.0.1:8001 FRONTEND_BROWSER_OUTPUT=outputs/frontend-check node scripts/validation/frontend_workbench_browser.mjs
GW_BASE_URL=http://127.0.0.1:8001 FRONTEND_BROWSER_OUTPUT=outputs/frontend-fixtures node scripts/validation/frontend_model_fixtures.mjs
```

Windows PowerShell按环境变量语法设置上述变量。完整手动添加使用已有 `scripts/validation/skill_authoring_browser.mjs`，必须显式设置一次性环境标记及管理员令牌；会新建草稿和执行记录，不能对正式数据运行。输出包含JSON检查记录与截图，不提交原始运行产物或令牌。
