## 固定设计

- 30 道题：15 个精确配置、5 个同义表达、5 个越界配置、5 个缺参配置。
- 每题执行 `off/on` 两组，每组重复 3 次；共 180 次，按冻结的随机顺序串行运行。
- 模型节点、提示词、参数、技能清单、工作流图、网关、executor 和独立物理校验器在批次前冻结。
- `skill_reuse_mode` 默认为 `on`；`off` 只关闭四个技能参考交付门，保留同一条工作流的其他条件。
- 原始 Dify SSE 以 gzip 保存；报告记录 trace 哈希，不记录 API 密钥。

## 边界与后续问题

本阶段证明的是冻结任务集上，服务端已接纳固定技能的真实交付、重新执行、物理正确性和量化收益。它不证明任意声学配置泛化、真人身份、自动学习安全性，也不认证模型供应商后台修订；工作流没有显式 seed，随机性不能宣称完全可复现。

项目仍有两个产品化缺口：运行时依赖 Dify，难以从 GitHub 下载后直接运行；当前工作流模型配置固定为 DeepSeek，不能按用户需求切换内核。解决方向、验收条件和迁移约束记录在 [`docs/KNOWN_GAPS.md`](../../KNOWN_GAPS.md)。
