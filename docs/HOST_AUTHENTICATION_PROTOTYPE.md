# 宿主认证设计与测试封套

当前没有生产认证机制。本轮标准库HMAC原型仅测试封套完整性、独立期望上下文、根撤回和跨请求重放拒绝；测试密钥在内存/测试fixture中，不生成生产凭据。不接入技能库、运行批准或生产执行器。authenticated和所有运行信任保持false。

生产机制需要独立宿主观察主体：宿主侧可信代理直接观察实际路由到固定executor的请求及响应，同时读取最小container/image/start/restart身份；代理独立重算run/nonce/代码、规范化参数、stdout哈希与执行窗口。前后Docker快照稳定不证明请求路由；仅上传JSON仍可伪造。

签名私钥应只在独立宿主代理；消费者只持公钥及操作者批准的根版本/撤回记录，技能代码和网关不可取得签名能力。HMAC验证者也能伪造，所以当前共享测试密钥不能作为该部署方案。生产非对称库、密钥供应、代理权限、认证传输均未实现/未授权部署，不安装依赖、不挂Docker socket给网关或技能。

参数绑定需要实际执行协议携带并由代理核对规范化参数，不能仅签名调用者自报参数哈希。固定recipe代码匹配可提供受限关联，不能泛化为任意代码参数真实性。

一次性消费需在同一可信消费者事务内重核当前根撤回/运行批准/派生生命周期/质量门控，再原子登记run+nonce+技能版本+证据摘要唯一键；失败拒绝注入。当前原型同一请求重复诊断允许，没有消费日志，不称通用防重放。

出口：先审查独立观察主体与请求路由可观测性，再选现成可用非对称实现并测试临时信任根；无根或批准维持空结果原生成回退。测试通过不证明真实宿主认证或物理正确。

## 公钥消费原型（本轮）

现成head-614b221-dev中cryptography 50.0.0可导入Ed25519，无安装或依赖变更。host_public_key_prototype仅公钥验证，私钥只在隔离单测内生成，不序列化、不保存；消费者不提供签名接口，也不接受封套附带公钥。固定域分离、16KB封套/8KBpayload、严格JSON与64字节签名、独立期望上下文、撤回拒绝已验证。导入库不可用则crypto_unavailable，不降级共享密钥。

该原型仍无受信根注册/代理/请求实际观察/参数协议/一次性消费，signature_matched仅数学验证结果，authenticated及全部可信字段false。cryptography现成存在不等于生产依赖合同或签名主体获批。K3仍未完成，不接网关或技能复用。

## 临时根与消费账本

host_consumption_prototype显式初始化临时SQLite；缺库不创建。根按连续版本只追加，撤回为终态；消费BEGIN IMMEDIATE内检查最新根、Ed25519签名及独立期望上下文，再以run+nonce唯一键登记摘要。并发只能一次成功，故障回滚后可重试。根/消费拒UPDATE/DELETE/REPLACE。它仅消费测试封套，不是技能注入授权，也未原子联查批准包/派生生命周期/物理门控；跨DB一致性仍未解决。测试消费成功authenticated与运行可信字段false。实际请求观察、参数协议、根部署与权限模型继续未实现。

## K3-HOST-FORWARD-JOINT：实际转发代码与测试消费
用户确认本人负责宿主观察器、公钥根批准及撤回。host_observer为独立宿主代码包，不复制入网关。固定配方/静态配置独立重算；直接数字IP HTTP转发、前后最小Docker身份与对端关联、40秒总截止、2MiB严格长度响应、无重试/重定向，返回摘要。host-only Ed25519入口只签自己的转发结果，公钥验证端无签名能力。根生成工具仅供操作者手动使用，加密私钥，独占创建且不批准/登记；本轮只在隔离测试临时目录生成测试根。
loopback替身实际HTTP及临时密钥签名验证，不是生产executor实跑。生产Docker身份前后只读采集一致，不证明已观察生产请求。所有认证字段false；无生产密钥/服务/DB/网络修改。
同DB测试消费原型详见SKILL_CONSUMPTION_TRANSACTION；完整生产主体批准、窗口/派发复核及正向复用仍未接。操作步骤见HOST_OBSERVER_ACTIVATION。
