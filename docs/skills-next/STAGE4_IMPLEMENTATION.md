# 阶段4：自动学习闭环

日期：2026-10-25。内部候选实现，默认关闭、生产未改，沿用显式schema18。阶段3的cd4c93e已验收：五项CI全通过，检查点为checkpoint/skill-stage3-20261025；该标签是开发验收标记，不是正式发行。

## 已实现

- 完整v2请求未命中已验证技能时，开启学习后由服务器生成受控首次求解。源automatic草稿、trial job及不可变controlled-source-job标记同事务保存，实际nonce/run/请求/代码/参数/runtime在派发前进入原attempt。普通history、伪造run或客户端成功声明不能产生授权来源。
- 首次结果保持Q2，仅有限、非零的完整受控复场允许进入观察；自动建学习草稿，绑定原来源run，触发新的独立验证。不得把第一次退出码0、模型摘要或候选数当接纳成功。
- 来源、稿、入队、验证、接纳和outbox审计幂等；中断后可补入队、补事件、补接纳。来源已完成但未观察也能后台补记，不再求解。unknown只核对历史，不重新派发；不支持类别用持久跳过标记，避免阻塞其他任务。
- 网关lifespan按显式开关启动一个进程内后台pump，5秒一次有界tick；同一数据库保持单执行名额和全局队头，定向领取避免看完队头后误抢其他任务。启动不迁移、不安装参考、不改配置；无新Redis/Celery服务。
- automatic来源由持久origin/不可变source标记判定，不能通过默认manual admit绕开。接纳事务重新检查学习开关、原来源当前状态/回执/实际文件，来源撤回与接纳在同库写锁竞争。事务末关闭学习则回滚技能、版本及admission；可保留真实验证事实。
- 初次求解展示不因学习后台失败而丢失，质量保持Q2；只有新的独立验证/接纳成功才供未来可信检索。学习状态绑定本次source/job，不能把另一个任务的admitted当本次成功。关闭学习后已独立验证技能继续可复用。
- 候选、验证、接纳、实际复用四类计数分开；原始异常、模型Key和本机路径不写进失败审计。源结果沿唯一gateway执行身份显示数值源归一化单位。

## 开关与运维

SKILL_LEARNING_ENABLED、SKILL_AUTHORING_ENABLED、SKILL_VALIDATION_ENABLED、SKILL_GENERAL_ADMISSION_ENABLED需同时true，默认关闭；检索另受原LIBRARY/RETRIEVAL/INJECTION控制。先备份显式迁移18并安装已审核runtime对应的参考政策，不能用开关绕过质量门。compose已有env_file，会传入.env中的开关；启动检查只读，不悄悄迁移旧库。

```bash
python -m scripts.skill_library.learning status
python -m scripts.skill_library.learning observe --run-id <server-source-run>
python -m scripts.skill_library.learning tick
```

命令只使用服务端配置，observe对无受控标记历史拒绝；tick一次只推进一项。状态关闭时不创建数据库。停止后台仅停止调度，有界join1秒，不杀未证明归属的executor；进程退出后的运行按原120秒租约转待核对，不能直接回queued。学习关闭不清除持久任务；重新开启后仍按来源与证据检查恢复。

## 本次真实验收

scripts/validation/skill_auto_smoke.py使用一次操作员参考政策安装后，自动推进三题首次求解→观察/验证→接纳→未来新run复用，不调用逐条验证/接纳命令。B03只预存源队列，由真实后台pump完成首次求解和验证接纳，覆盖排队后恢复。

结果：3候选、3验证通过、3接纳、3实际复用；共9次原executor求解（3源+3独立验证+3复用），重放来源不增技能/版本；关闭学习后3次已验证复用仍通过。B01/B02/B03幅值误差保持0.0338672%/0.0323398%/1.938952%，原严格上限1%/1%/3%。原2CPU/4GiB/30秒、只读、10001、cap-drop与隔离网络保持，无付费模型、无生产三库写入；原沙箱只有求解代码，没有参考数组挂载。

新回归覆盖来源缺失/篡改/角色变化、零场、取消/归档、缓存缺失、关闭学习、提交回滚、定向领取、并发重放、入队/outbox中断、terminal补观察及默认admit绕过防护。合成数组只测试机制，科学通过来自上述真实求解。原依赖全量结果见CHANGELOG。

## 范围和下一阶段

自动学习只积累受控技能，不训练模型权重。当前独立参考仍限三题精确幅值范围，不认证相位或任意参数泛化。完整v2参数/结果合同需用户明确提供，模型不能猜缺参；本次真实探针未调用付费模型，不代表所有自然语言解析都已验收。手动添加表单/导入/状态查看在阶段5，浏览器全流程与发布回滚在阶段6。
