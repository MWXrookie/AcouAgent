## 4. 不可变误差口径

令A为本次实际计算的完整复场，R为锁定k-Wave完整复数参考，均为128×128。验证器独立计算：

```text
I = [16:112,16:112]                         # 每侧裁剪16，内部96×96
D = abs(abs(A) - abs(R))
E = max(D[I]) / max(abs(R))                 # 分母为完整128×128参考
pass_numerical = E < limit                  # B01/B02=.01；B03=.03
```

不能把分母改成裁剪区峰值、实际场峰值、逐点参考、平均值或RMS；不能把1%写成1.0。阈值处相等即失败。不以额外四舍五入、重归一化、幅值拟合、插值、掩掉源点、转置、翻转、相位旋转后择优等方式改变评分。阶段0应以合成数组把分子/分母区域差异及边界行为直接测出。

该原始规则**只比较模，不比较相位**。保存完整复场以保持结果合同与可审计性，但“通过本profile”不证明相位正确，也不证明其他物理量或参数正确。R必须有限且全域峰值>0；A必须有限、形状/单位约定/轴序正确，否则结构性拒绝，而不是计算NaN后误放行。
