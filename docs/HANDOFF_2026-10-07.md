**推荐封装**（Windows 工作区里已有 `vm-ssh.ps1`）：

```powershell
.\vm-ssh.ps1 "docker ps"                        # 单条命令
.\vm-ssh.ps1 -ScriptFile .\task.sh              # 多行脚本（base64 传输，自动处理 CRLF/引号）
```

> 为什么用 base64 而不是管道：PowerShell 向原生命令的 stdin 写多行文本时会**多追加一个 CR**，bash 会把 `\r` 当命令执行。这是踩过的坑。

## 7. 工作纪律与授权边界

**必须遵守**（摘自规划与提交规范）：

- **不擅自**：`docker system prune`、删卷/镜像/项目数据、提交、推送、部署、重启在用服务、跑付费评测
- **executor 红线不可削弱**：`read_only`、`cap_drop ALL`、`no-new-privileges`、限额、无外网；技能代码必须经 executor，**禁止网关内 `exec()`**
- **临时脚本用完即删**；只有会重复使用的才进 `scripts/`
- **每轮记 CHANGELOG + 时间台账**；**不重置预算、不把未知报成精确**
- **不为勾选降低阈值**、不删失败样本、不把真人/付费验收替换成模拟
- 不提交 `.env`/`.env.bak.*`/日志/缓存/tar 包/本机绝对路径

**需要单独授权**：提交、推送、部署、重启现有服务、付费模型评测、真人 UAT、发布。
