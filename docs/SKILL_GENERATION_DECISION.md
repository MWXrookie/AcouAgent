# 生成前回退决定合同
状态：独立后端接口已实现，未部署Dify，未实现正向认证消费。

内部 generation_context 在主开关、检索和注入开关均严格True时使用 prepare→consume；默认关闭不访问SQLite。公共search仍为只读，不写此账本。

schema10的决定记录与消费记录只追加，拒绝UPDATE/DELETE/REPLACE，包括不同decision_id抢占相同generation_run_id。决定记录规范化查询SHA、原上下文SHA、服务端UUID/nonce、创建及30秒失效时刻和最多3条版本元数据。原上下文、原参数、代码不写入这两个表。

准备及消费分别BEGIN IMMEDIATE；消费不迁移或创建缺失数据库，同事务重新核对查询、上下文、nonce、服务端时钟和最新元数据快照；缺失、漂移、过期、重放、写失败均空回退。元数据失效时仍只能记录回退，不注入。每决定只能消费一次，每generation_intent_id只能关联一次；并发只一次成功，插入失败回滚后可以重试。

消费只证明控制器记录一次generation_fallback_intent，不能证明模型真正运行、技能真正使用或用户身份。内部generation_context自动完成该记录，但不调用模型/执行器/网络；审计失败保留原上下文且不重放消费。全部可信字段保持false。不存在可调用的MCP/HTTP正向入口。

反馈来源关联用部分JSON表达式索引和版本来源索引；仅相关事件建索引。最近三个不同来源运行从两条有序索引各取最多101条；如果截断/同时间边界不足以证明最近三条，拒整笔反馈，不删除历史或扩大预算。源运行关联仍不是真实使用关联。

临时v9→v10升级保留记录；索引名冲突导致整个升级回滚，纠正冲突后可重试；旧非法JSON不会破坏安全索引。未迁移生产库。

## 同权威库宿主诊断与剩余权限边界
schema10同库根/派发/诊断表由skill_authority及skill_host_intake使用，不ATTACH其他WAL库。根窗口与具体run批准分开签名，根撤回终态；每次诊断消费同事务复核最新revision/有效期/代码配置/输出与候选生命周期。候选宿主证据与审计一起提交或一起回滚，不作可信率或实际用户使用。
反馈可引用已记录宿主摘要但trust_verified和actual_use_authenticated恒false。生成前决定依旧仅空回退；没有提交后交付可信代码的正向消费者。生产签名与独立主体接入、真正物理/召回及当前Dify消费未验收。
合成预筛基准覆盖频率、逐轴dx及过期生命周期，127条夹具/9查询/cutoff3；近期不兼容记录在50返回量之前SQL筛掉，之后严格JSON/边界/派生复核。该基准不是生产召回验收。

签名根策略每次消费也重核原类型/期限上限；合法数学签名不能豁免导入记录的布尔或超长窗口。登记根策略在BEGIN IMMEDIATE取得锁后读取当前时间，避免等待期间过期。两个导入异常策略回归拒绝且无派发行。
